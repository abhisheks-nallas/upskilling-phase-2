# Security and Data Handling

## Data classification
Company data is labelled Public, Internal, Confidential or Restricted. Customer data is always Restricted. Restricted data must stay on company systems, so it may never be copied to personal devices, personal email or personal cloud storage.

## Reporting incidents
Report any suspected security incident, such as a lost laptop, a leaked password or a suspicious login, to the security team within 1 hour. Use the #security-incident channel or the security hotline. You will not be blamed for reporting a mistake quickly, but hiding one is a disciplinary matter.

## Phishing
Do not click links in unexpected emails asking for passwords or payments. Use the "Report phishing" button in your mail client. Phishing tests are sent to all employees every quarter, and anyone who fails a test completes a short refresher course.

## Using AI tools
Only company-approved AI tools may be used for work. Never paste customer data, source code marked Confidential, secrets or personal data into public AI chat tools. Approved tools are listed on the internal wiki, and new tools need a security review before use.

## Clean desk
Lock your screen when you step away. Do not leave printed Confidential documents on your desk overnight, and shred them in the bins provided.
